# MRAI — Tumor Segmentation & 3D-Export Engine

A browser demo of a custom-trained 3D U-Net (Fully Convolutional Network) that detects and contours
brain tumors in MRI volumes, computes true-scale physical volume, and exports 3D-printable STL meshes.

Click **Load Sample Case** for a zero-setup demo on a real BraTS20 validation scan, or upload your own
NIfTI (`.nii` / `.nii.gz`) file.

Full source and the desktop (Tkinter) version of this app: see the linked GitHub repository.
